# Bank System Simulation

This project simulates a banking system that processes various types of transactions over a week-long period.

## Directory Structure

### `/frontend`
Contains the frontend implementation of the banking system:
- `main.py`: Main entry point for the frontend application
- `paybill.py`: Handles bill payment transactions
- `transfer.py`: Handles money transfer transactions
- `withdrawal.py`: Handles withdrawal transactions
- `deposit.py`: Handles deposit transactions
- `create.py`: Handles account creation
- `delete.py`: Handles account deletion
- `disable.py`: Handles account disabling
- `changeplan.py`: Handles plan changes
- `check.py`: Contains validation logic for various operations
- `interactive_session.py`: Handles interactive user sessions

### `/backend`
Contains the backend implementation:
- `main.py`: Main entry point for the backend application
- `transaction.py`: Defines the Transaction class and related functionality
- `transaction_processor.py`: Processes transactions and updates account information
- `print_error.py`: Handles error logging and display

### `/input`
Contains daily transaction input files:
- `day1_session1.inp` to `day7_session3.inp`: Input files for each day's three sessions
- Each session file contains login information and transaction commands

### `/output`
Stores transaction output files:
- `day1_session1.etf` to `day7_session3.etf`: ETF (Electronic Transaction File) for each session
- `day1_merged_txns.txt` to `day7_merged_txns.txt`: Merged transaction files for each day
- The `.out` files correspond to the front-end output of the respective inputs with the same name.

### `/current_accounts`
Stores current account files:
- `day1_current_accounts_file.txt` to `day7_current_accounts_file.txt`: Account information for each day
- `day8_current_accounts_file.txt` is generated by work on day 7 and for future work

### `/master_accounts`
Stores master account files:
- `day1_master_accounts.txt` to `day7_master_accounts.txt`: Master account information for each day
- `day8_master_accounts.txt` is generated by work on day 7 and for future work

### `/example_input`
Contains sample input files for more testing (they are from Phase 1 and are all valid input):
- Various test cases for different transaction types
- Organized by transaction type (withdrawal, transfer, bill payment, etc.)

## Test steps
1. Delete all files in `/output`
2. Delete files in `/current_accounts` and `/master_accounts` starting from
day2. (Do not delete files related to day1, as they are used for the first day of the run)
3. Run any of the follow scripts according to your preference.
4. Check the results.

## Scripts

### `run_daily.sh`
This script processes transactions for a single day.

**Usage:**
```bash
./run_daily.sh <day_number>
```

**Example:**
```bash
./run_daily.sh 1
```

**Functionality:**
1. Processes three sessions for the specified day
2. Merges transaction files from all sessions
3. Runs backend processing to update account information
4. Generates next day's account files

### `run_weekly.sh`
This script simulates the bank system's operation over a week.

**Usage:**
```bash
./run_weekly.sh
```

**Functionality:**
1. Runs the daily script for each day (1 through 7)
2. Ensures proper file generation between days
3. Maintains account state throughout the week
4. Provides progress updates and error handling

### `run_interactive.sh`
This script allows for interactive testing of the banking system.

**Usage:**
```bash
./run_interactive.sh <day_number>
```

**Example:**
```bash
./run_interactive.sh 1
```

**Functionality:**
1. Starts an interactive session for the specified day
2. Allows users to enter commands directly
3. Saves the session output as a new session for the day (e.g., day1_session4.out/etf)
4. Merges the interactive session with the daily transaction file
5. Provides a help command to list available options

**Interactive Commands:**
- `login` - Start a new session
- `withdrawal` - Withdraw money from an account
- `transfer` - Transfer money between accounts
- `paybill` - Pay a bill to a company
- `create` - Create a new account (admin only)
- `delete` - Delete an account (admin only)
- `disable` - Disable an account (admin only)
- `changeplan` - Change an account's plan (admin only)
- `logout` - End the current session
- `exit` - End the interactive session
- `help` - Show available commands

## File Formats

### Current Accounts File Format
```
[account_number] [account_name] [status] [balance] [plan]
```

### Master Accounts File Format
```
[account_number] [account_name] [status] [balance] [plan]
```

### Transaction File Format
```
[transaction_code]_[username]_____[account_number]_[amount]_[misc]
```

## Transaction Codes
- `01`: Create Account
- `02`: Delete Account
- `03`: Paybill
- `04`: Deposit
- `05`: Withdrawal
- `06`: Transfer
- `07`: Change Plan
- `08`: Disable Account

## Company Codes
- `EC`: Electric Company
- `CQ`: City Water
- `FI`: Internet Provider
